# Anti Patterns

cmobank-cmo が避けるべき判断ミスと、見つけたときの修正方法です。

## 1. SWOT や 3C で満足する

問題:

SWOT、3C、財務整理は材料であって、CMO ワークの中心ではありません。それだけでは、どの需要で No.1 を取るかが決まりません。

修正:

```text
この整理を、需要・供給・コミュニケーションの一文へ変換すると何か。
```

## 2. 人・属性でターゲットを切る

悪い例:

- 30代女性
- 経営者
- 初心者
- シニア層
- BtoB 企業

問題:

人で切ると、競合も同じ発想になり、市民プールに流れます。

修正:

```text
その人たちの頭の中にある「何をしたい / 何に困っている / どうなりたい」需要か。
```

## 3. 提供形態を需要と誤認する

悪い例:

- 月額コミュニティ
- オンライン講座
- サブスク
- 無料相談
- AI ツール

問題:

提供形態は供給側の都合であり、需要ではありません。

修正:

```text
その形態によって、見込み客はどんな欲求・痛みを解決したいのか。
```

## 4. 強みから需要を後付けする

悪い例:

```text
我々は AI に強い。だから AI 研修には需要があるはずだ。
```

問題:

これは供給の罠です。コアに旗を立てることと、需要を後付けすることは違います。

修正:

```text
AI というコアが、需要側のどんな強い痛みに最も効くのか。需要側で本当に欲しさがあるか。
```

## 5. 複数需要を同時に狙う

悪い例:

```text
若手にも経営者にも、個人にも法人にも売る。
```

問題:

リソースが分散し、どの需要でも No.1 を取れません。

修正:

```text
最初に No.1 を取る需要はどれか。他の需要は、いつ・どの条件で取りにいくか。
```

## 6. 「市場が大きい」だけで選ぶ

問題:

大きい市場は魅力的ですが、No.1 を取れなければ消耗戦になります。

修正:

```text
この市場の中で、自社が第一想起になれる需要の広さはどこか。
```

## 7. コンセプトが全部入りになる

悪い例:

```text
安くて高品質で簡単で安心で、初心者にも上級者にも使える。
```

問題:

価値が絞れておらず、誰のどんな需要にも深く刺さりません。

修正:

```text
1 つの狙う需要に対して、最も刺さる 1 つの価値は何か。
```

## 8. ベネフィットではなく特徴を約束する

悪い例:

```text
高性能 AI を搭載しています。
```

問題:

人は特徴ではなく、特徴を通して手に入る感情・状態を買います。

修正:

```text
その特徴によって、見込み客はどんなポジティブな感情や状態を手に入れるのか。
```

## 9. 信じる理由がない

悪い例:

```text
あなたも最短で売上が伸びます。
```

問題:

ベネフィットだけでは「うますぎる話」になります。証拠が必要です。

修正:

```text
なぜそれが信じられるのか。実績、仕組み、データ、顧客の声、保証は何か。
```

## 10. LP を商品説明にする

問題:

LP は商品を説明する場所ではなく、取引を成立させるコミュニケーション設計物です。

修正:

```text
各行は MOA に近づけているか。商品説明ではなく、脳内情報空間を書き換えているか。
```

## 11. 教育で商品説明を始める

悪い例:

```text
当社の商品には遠赤外線機能があります。
```

問題:

読者が選ぶモノサシを持つ前に商品説明をしても、売り込みと取られます。

修正:

```text
商品名を出す前に、「何で選べばいいか」というモノサシを渡す。
```

## 12. 媒体選定から始める

悪い例:

```text
TikTok をやるべきか、YouTube をやるべきか。
```

問題:

上流の狙う需要と商品コンセプトが決まらないまま媒体を選んでも、何を誰の脳内に届けるかが定まりません。

修正:

```text
先に、どの需要で No.1 を取るか、どんな価値を届けるかを決める。
```

## 13. 検証が追認になる

問題:

仮説を正当化する情報だけを集めると、崩れている仮説を見逃します。

修正:

```text
この仮説が間違っているとしたら、どんな兆候が出るか。
```

## 14. 小手先のピボットで延命する

問題:

重要仮説が崩れているのに、価格やコピーだけを少し変えても根本は直りません。

修正:

```text
崩れているのは需要か、供給か、コミュニケーションか。土台が崩れているなら大きく変える / やめる。
```

## 15. 確信のない提案で終わる

悪い例:

```text
この方向性もあり得ると思います。
```

問題:

社長は事実の整理や弱い可能性では動きません。仮説と根拠を持った確信の言葉が必要です。

修正:

```text
この需要は青く、自社のコアが活き、No.1 を取れる。だからここで戦うべきです。
```

ただし、その確信は市場で検証すべき暫定解として扱います。
