# CMOBANKマーケティングノウハウ本 章構成案

## 序章　マーケティングとは、需要と供給をつなぐことである

1. マーケティングとは需要と供給をつなぐ活動である
2. ビジネスの目的、Business Goal から逆算する
3. 思考は「需要 → 供給 → コミュニケーション」の順に進む
4. 4つのゲート：Demand-Based / Sufficient / Right to Win / Communicable
5. 常に全体像のどこにいるかを自己定位する

## 第1章　ビジネスとは、需要に対して供給を届け、報酬をもらうことである

1. ビジネス＝需要に供給を届けて取引する行為
2. 需要・供給・取引の最小構造で考える
3. 良い取引は相乗効果、シナジーを生む
4. 購買は機能ではなく感情、ベネフィットで起きる
5. 需要は満たされるたびに、新欲求から新需要を生む
6. 供給は需要を満たすために進化する
7. コミュニケーション＝情報を伝達して取引を促すこと

## 第2章　欲求から需要が生まれ、その需要に対して商品を入れる

1. 欲求＝何かを欲する心
2. 需要＝欲求の解決策として生まれるもの
3. 欲求があれば売れる、ではない
4. 欲求 → 需要 → 取引 → 感情
5. 感情はシーンで捉える
6. 需要は〈欲求 × 脳内情報空間〉で生まれる可変なもの
7. 事業では需要を見る、コミュニケーションでは欲求に立ち返る

## 第3章　マーケターの3つの問い

1. ①どの需要でNo.1を取るか
2. ②どのような供給を提案するか
3. ③どのようにコミュニケーションするか
4. マーケティングの良し悪しは、需要の切り取りとNo.1の取り方でほぼ決まる
5. 人ベース・媒体ベースではなく、需要ベースで切る
6. 上流は「狙う需要・商品コンセプト・コミュニケーション」を決める部分である
7. Step2〜5は相互に行き来して精度を高める

## 第4章　リサーチ8割：鳥の目・虫の目・魚の目

1. リサーチには、情報収集と憑依による想像が含まれる
2. 鳥の目：市場全体・市場規模・STPを見る
3. 虫の目：個別の見込み客の頭の中を見る
4. 魚の目：時間軸・トレンド・変化を見る
5. 情報を頭に大量投入して、まず発散する
6. リサーチマップ＝マーケティング活動に必要な情報すべて
7. 表現が出ないのは、インプットが足りないからである

## 第5章　ペルソナ脳内マップ：人の頭の中に憑依する

1. 最もミクロなのは、人の脳内である
2. 表面的な客観的予想ではなく、日常に入り込む
3. ペルソナの脳内で行われている思考を言語化する
4. 感情が動くシーン・瞬間を言語化する
5. 質問は、需要・痛み・ベネフィット・選ぶ基準を探るためにする
6. n=1の仮説は、複数人で検証する
7. 憑依の解像度が、差別化できる深い情報を生む

## 第6章　青い需要と狙う需要

1. 青い需要＝競合が少ない・人数が多い・購入意欲額が高い
2. 赤い需要＝競合が多い・人数が少ない・購入意欲額が低い
3. 大きい市場でNo.1が取れるところを探す
4. 需要は一段ずつ広げたり狭めたりして確定する
5. 人で切るな、需要で切れ
6. 市民プールで泳ぐな
7. 魚の目で、未来に広がるか・未来も赤くならないかを見る
8. 狙う需要＝複数の青い需要の中から「ここで戦う」と決めた需要

## 第7章　商品企画マップ：特徴・効果・ベネフィット・証拠に分解する

1. 製品と商品は違う
2. 特徴＝商品が持つ客観的性質
3. 効果＝特徴から起きる客観的変化
4. ベネフィット＝商品を通して手に入るポジティブな感情
5. 証拠＝ベネフィットを信じさせる材料
6. 特徴があるから買うのではない
7. ベネフィットが信じられる・納得できるから買う
8. ベネフィット → 特徴・効果 → 証拠の順で伝える

## 第8章　商品コンセプト：狙う需要と製品を結ぶ橋

1. コンセプトとは「この感じ」を端的に表したもの
2. 商品コンセプト＝「誰に・どんな価値」を一点に絞り込んだもの
3. 商品コンセプトは、製品を価値に変換する核である
4. コンセプトは思考のためのツールであり、原則そのまま表に出さない
5. 製品 → 商品コンセプト → 需要
6. 良い商品コンセプトの5条件
7. USP＝独自の売りの提案
8. キャッチコピー＝人の注意を引くための宣伝文句
9. 目的 → コンセプト → 伝える内容 → 表現

## 第9章　セールスとオファー：取引をイエスと言わせる

1. セールス＝オファーに対してYESと言ってもらい、取引を成立させること
2. オファー＝取引条件の提示
3. 良いオファーの4要素：お得感・低リスク・今やる理由・わかりやすさ
4. セールスの4点セット：ベネフィット・正しい痛み・No.1の理由・厚いオファー
5. セールスでは「買う理由」を作る
6. 完璧なオファーでも、人は買わない
7. 3つのNot：Not Read / Not Believe / Not Act

## 第10章　脳内情報空間とコンテンツ

1. 脳内情報空間＝頭の中に広がっている世界
2. 伝わる＝相手の脳内情報空間が意図どおり書き換わること
3. ゴールの脳内情報空間から逆算する
4. MOA＝行動を起こす瞬間の脳内情報空間
5. コンテンツ＝脳に刺激を与える情報
6. 脳内情報空間の外側を狙う
7. 1.5メートル理論：近すぎても遠すぎてもダメ
8. whatを一文に確定し、howで演出する
9. ビッグアイデア＝FV

## 第11章　LPとコミュニケーションファネル

1. LPは商品を説明する場所ではなく、取引を成立させるコミュニケーション設計物である
2. LPは、読者の脳内情報空間をMOAに必要な状態へ書き換える情報の連なりである
3. 共感 → 教育 → 約束 → 交渉 → 提示
4. 共感＝欲求、教育＝需要、約束＝商品、交渉＝オファー、提示＝理想
5. 教育＝需要・欲求の教育、約束＝商品説明
6. コミュニケーションファネル＝リーチ → セールス（見込み客獲得）→ セールス（CRM）
7. 媒体はすべて人によって作られたもの
8. 画面の向こう側に人がいる
9. 媒体の価値は、人数 × 時間 × 姿勢で見る
10. ワイヤーフレームは白黒で作る
11. コピーキャットで構造を抽出する

## 第12章　CMOワーク：どの需要でNo.1を取り、そこへどう至るか

1. 現状を需要・供給・コミュニケーションで分解する
2. どの市場でNo.1になるかを考える
3. No.1を取る市場は、コアコンピタンス起点、網理論で探す
4. コアコンピタンスを炙り出す
5. そのコアが最も活きる青い需要を選ぶ
6. 絶対選ばれる商品コンセプト・ポジショニングを作る
7. No.1に至るまでのマーケティング戦略を社長へ提案する
8. センターピンにオーバーリソースを投下する
9. 重要仮説を最速で検証する
10. 仮説が崩れたら、撤退・変更を判断する

## 終章　答えを壊し続ける：本当の答えは思考の外にある

1. フレームワークの暗記ではなく、全体像の中で役割を掴む
2. リサーチ量こそが表現を生む
3. 表現は自分の頭の中からしか出ない
4. いまの出力は暫定解にすぎない
5. これでいいと思った瞬間ほど壊しにかかる
6. 最終的には市場でテストする
7. 手段を目的化せず、大目的から逆算する
8. マーケティングはプラス・プラスのために使う
